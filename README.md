DESCRIPTION

This database schema is designed for a Boutique Enterprise. The system supports fast paced transaction environments that require real time synchronization between
checkout terminals, centralized inventory management and customer management tools.

MAIN FEATURES

Stock tracker: keeps an accurate count of your product, groups them into category and tracks which supplier they come from
Easy checkout: Quickly calculates subtotals, apply the right sales taxes and process customer purchases
Customer profiles: saves customer purchase history that can be used to give them personalized shopping discounts
Different payment options: allow the customer to pay using different payment methods
Staff access levels: restrict system access based in job roles eg. cashier can only see the sales while the manager can handle the settings and inventory
Digital receipt & logs: automatically saves a permanent, unchangeable copy of every sale to print receipts and keep the business records safe
